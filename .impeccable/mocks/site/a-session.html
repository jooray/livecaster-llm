The paperwork is already written

A slower, better model reads the whole transcript and writes the notes in the language of the podcast: a summary, what was covered and what was not, chapters with timestamps, titles and descriptions to choose from, a social post, quotes, and mentions with links — or an explicit link TODO where it could not find one, because it says so instead of inventing a URL.

Click any block to copy it. The social post arrives without its heading, ready to paste.

Running it

# macOS on Apple Silicon
uv sync --extra mac

# Linux, or --extra cuda with an NVIDIA GPU
uv sync --extra linux

export VENICE_API_KEY=...
uv run livecaster check
uv run livecaster run outlines/my-episode.md

Python 3.12 and uv. The first run downloads about 2.4 GB of model weights, so not five minutes before a recording.

Before you try it

  • Parakeet detects the language itself and cannot be told which one to use. You can lock the language in the UI, or switch to Whisper, which honours it at ten times the latency.
  • Opening a Bluetooth headset's microphone drops the whole link to 16 kHz mono. That is macOS, not Livecaster — use a wired or USB microphone for a real episode.
  • With one shared microphone there are no speaker labels, and the app does not pretend otherwise.
  • On macOS the system-audio permission is granted to your terminal app, and some terminals never raise the prompt. BlackHole is the documented fallback.
