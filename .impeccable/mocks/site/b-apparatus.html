local transcription, remote reasoning

A live co-pilot for podcast hosts. It transcribes on your own machine while you record and keeps your outline as a map of the episode rather than a script. What it claims, it claims from real sessions — and what it cannot do is on this page too.

Watch a session Source on GitHub

The outline becomes a map, not a script

Livecaster reads the Markdown you already write and follows the conversation against it. Covered lines take a single cut with the time beside them; a section you have finished folds to one line; the one topic that just became reachable is set large, with the reason it lit up and a sentence you could use to get there.

It never autoscrolls, never advances on your behalf, and never reorders your document. Every state it proposes can be overridden with a click or a key.

Audio never leaves the machine

Transcription runs locally and the WAV backups are written beside the session. What crosses the network is the outline text, the transcript text, and the state derived from them. The provider's injected system prompt is disabled and web search is off.

The outline file itself is opened for reading and never for writing. Everything the app produces goes into a session directory of its own.

It costs about fifty cents for a two-hour episode

A tick every twenty-five seconds is cheap because most of each prompt comes back from the provider's cache. The wrap-up at the end is the expensive half, and its price is set by the length of the notes it writes rather than the transcript it reads.

What you get when you press Finish

Notes in the language of the podcast: a summary, what was covered and what was not, chapters with timestamps, titles and descriptions to choose from, a social post, quotes, and mentions with links — or an explicit link TODO where it could not find one.

Click any block to copy it, without its heading, ready to paste.

Running it

# macOS on Apple Silicon; --extra linux or --extra cuda elsewhere
uv sync --extra mac
export VENICE_API_KEY=...
uv run livecaster check
uv run livecaster run outlines/my-episode.md
Apparatus
Where the map comes from
A tick every ~25 s sends the recent transcript and the state of the outline to a fast model. deepseek-v4-flash-0731-fast, ~9 s to answer
Cost per tick
$0.0009 averaged over real sessions.
Cost of the wrap-up
$0.14 – 0.20 on short episodes. claude-sonnet-5 through Venice
A whole live session
$0.17 for six minutes, eleven ticks, nothing failed.
Two-hour episode
about $0.50. The target was under a dollar.
Language
Parakeet detects the language itself and cannot be told which one to use. On poor audio it drifts — a Slovak recording through a Bluetooth headset came back partly in Polish. Locking the language in the UI fixes the notes, not the words.
Microphones
Opening a Bluetooth headset's microphone drops the whole link to 16 kHz mono. That is macOS, not Livecaster.
Speakers
One shared microphone means no speaker labels, and the exports handle their absence rather than guessing.
System audio on macOS
The permission is granted to your terminal app, and some terminals never raise the prompt. BlackHole is the documented fallback.
What it is not
Not a teleprompter, not a recorder of record, and not a cloud transcription service.
Requirements
Python 3.12 and uv. macOS or Linux. First run downloads ~2.4 GB of weights. a Venice API key, prepaid
